# 1005 k次取反后最大化的数组和

[leetcode链接](https://leetcode.cn/problems/maximize-sum-of-array-after-k-negations/description/)

给你一个整数数组 nums 和一个整数 k ，按以下方法修改该数组：

选择某个下标 i 并将 nums[i] 替换为 -nums[i] 。
重复这个过程恰好 k 次。可以多次选择同一个下标 i 。

以这种方式修改数组后，返回数组 可能的最大和 。

```
示例 1：

输入：nums = [4,2,3], k = 1
输出：5
解释：选择下标 1 ，nums 变为 [4,-2,3] 。
示例 2：

输入：nums = [3,-1,0,2], k = 3
输出：6
解释：选择下标 (1, 2, 2) ，nums 变为 [3,1,0,2] 。
示例 3：

输入：nums = [2,-3,-1,5,-4], k = 2
输出：13
解释：选择下标 (1, 4) ，nums 变为 [2,3,-1,5,4] 。
```

# 解答

我们可以使用贪心算法，算法的逻辑是；先找负数最小的去翻转，如果负数都翻完了，就翻此时最小的正数。具体一点步骤如下：

1. 先排序数组按照从小到大排序
2. 从负数开始遍历，如果当前是负数，翻转，k--，并且向后移一位。
3. 如果负数都翻转完了k还是大于0，那么就找到此时最小的正数。
4. 此时最小的数要从0的左右两边开始找。
5. 找到最小的正数，如果k是奇数，那么把最小正数翻转即可，如果是偶数，则不需要翻转。
6. 求数组的和

按照上述步骤写出的代码如下：

```javascript
var largestSumAfterKNegations = function (nums, k) {
    nums.sort((a, b) => a - b);
    let minIndex = -1
    let minValue
    for (let i = 0; i < nums.length; i++) {
        if (nums[i] < 0 && k > 0) {
            nums[i] = -nums[i]
            k--;
        }
        if (nums[i] >= 0) {
            if(minValue === undefined) {
                minValue = nums[i]
                minIndex = i
            } else {
                if(nums[i] < minValue) {
                    minValue = nums[i]
                    minIndex = i
                }
            }
        }
    }
    if (k > 0) {
        if(k % 2 === 1) {
            nums[minIndex] = -nums[minIndex]
        }
    }
    return nums.reduce((acc, curr) => acc + curr, 0)
};
```
